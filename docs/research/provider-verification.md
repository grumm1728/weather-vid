# Open-Meteo verification for the browser release

Verified against provider documentation on November 17, 2026. This supplements the provider comparison in [issue #2](https://github.com/grumm1728/weather-vid/issues/2) and supports the data decision in [issue #6](https://github.com/grumm1728/weather-vid/issues/6).

## Hosted access and attribution

- Select Open-Meteo for both forecast and location search. The keyless hosted tier is suitable for development and a release that qualifies as non-commercial. It excludes ads, subscriptions, commercial products, and promotional activities. Confirm eligibility for the actual sfxmath.com deployment before using this tier in production. If it is commercial or eligibility is uncertain, use the paid Standard plan or hold the live release until there is an eligible deployment. [Terms](https://open-meteo.com/en/terms) · [Pricing](https://open-meteo.com/en/pricing)
- The keyless tier publishes limits of 600 calls per minute, 5,000 per hour, 10,000 per day, and 300,000 per month, with no uptime guarantee. Limits apply by IP and application. The provider warns that shared egress platforms such as Vercel can hit limits earlier. A 15-minute polling cadence costs up to 96 regular weather calls per continuously visible session per day, plus fetches for location changes, searches, and retries. Usually one HTTP request counts as one call. Larger weather requests can count as more. [Terms](https://open-meteo.com/en/terms) · [Pricing](https://open-meteo.com/en/pricing)
- Standard includes forecast and geocoding and lists a 1 million calls per month budget. Use `customer-api.open-meteo.com/v1/forecast` and `customer-geocoding-api.open-meteo.com/v1/search` with the `apikey` parameter, behind same-origin server routes. Store the key server-side and omit it from browser bundles, responses, and logs. [Pricing](https://open-meteo.com/en/pricing) · [Official geocoding URL generator](https://github.com/open-meteo/open-meteo-website/blob/main/src/routes/en/docs/geocoding-api/%2Bpage.svelte)
- Link to Open-Meteo alongside the weather display and credit Open-Meteo and GeoNames where search results or their place names are displayed. Include a CC BY 4.0 link and describe transformations such as grouping condition codes for the animation. The data licence and the hosted service terms apply separately. [Open-Meteo licence](https://open-meteo.com/en/licence) · [Geocoding attribution](https://open-meteo.com/en/docs/geocoding-api#attribution) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

## Browser API contracts

- Fetch `https://api.open-meteo.com/v1/forecast` at the selected location's WGS84 coordinates with `current=temperature_2m,weather_code,is_day`, `timeformat=unixtime`, and `timezone=auto`. Use `current.time` as the valid time, compare it as UTC epoch seconds for age checks, and use the returned IANA time zone for display. Receipt time can track request behavior. Current conditions are model estimates at 15-minute intervals, with interpolation where native 15-minute data are unavailable. Keep the original condition code available to normalization, cover the documented WMO table including code `97`, and handle unknown codes explicitly. [Forecast docs](https://open-meteo.com/en/docs) · [WMO code table](https://open-meteo.com/en/docs#wmo_weather_interpretation_codes)
- Fetch `https://geocoding-api.open-meteo.com/v1/search` using a submitted city or postal code as `name` and bound the result count. Global results include stable IDs, names, coordinates, and available disambiguation fields such as region and country. Empty and single-character queries return no matches, two-character names require an exact match, and longer ones support normalized prefix matching. A country or first-level administrative area may follow a comma. Optional result fields can be absent. [Geocoding docs](https://open-meteo.com/en/docs/geocoding-api)
- Keyless cross-origin browser fetches are a reasonable starting point. With `Origin: https://sfxmath.com`, a live geocoding probe returned HTTP 200 and `Access-Control-Allow-Origin: *`. The forecast probe timed out on both attempts. The forecast project advertises CORS. Verify successful browser requests to both hosts in a Vercel preview and on the final origin. [Weather repository](https://github.com/open-meteo/open-meteo) · [Geocoding demo implementation](https://github.com/open-meteo/open-meteo-website/blob/main/src/routes/en/docs/geocoding-api/%2Bpage.svelte)
